# Mariage Jimmy & Joidie – Invitations QR

Application web pour gérer les invitations avec QR code et l'accueil des invités.

- **Invités** : liste des invitations, cartes avec QR code à envoyer par WhatsApp.
- **Scanner** : scan en direct avec la caméra du téléphone à l'entrée.
- **Présences** : qui est arrivé, qui est absent, export Excel/CSV.

Les données (noms des invités) ne sont **pas** dans ce dépôt : elles sont dans Firebase Firestore,
protégées par un code d'accès réservé à l'équipe d'accueil.
